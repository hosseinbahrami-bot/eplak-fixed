# آزمون‌های عکس و فیلم (ابزار توسعه — بخشی از اپ نیست)

این پوشه آزمون‌های خودکار «بارگذاری عکس و فیلم» را نگه می‌دارد. هیچ‌کدام روی سرور
تولیدی اجرا نمی‌شوند و در گیت فقط برای توسعه‌دهنده نگه داشته شده‌اند.

## نصب پیش‌نیازها (یک‌بار)

```bash
cd tools/.media-e2e
npm i          # php-wasm + php-wasm-sqlite + jsdom + fake-indexeddb
```

> پوشه‌ی `node_modules` در گیت نیست؛ اگر تازه کلون کرده‌اید، این دستور را اجرا کنید.

## اجرای آزمون‌ها

| دستور | توضیح |
|---|---|
| `node harness.mjs` | آزمون سرتاسری اندپوینت‌های PHP (آپلود/فهرست/اتصال/حذف) روی PHP واقعی با SQLite |
| `node frontend.test.mjs` | آزمون منطق سمت کاربر در jsdom (پیش‌نمایش، شمارنده، حذف، گالری جزئیات، صف) |
| `node live.test.mjs` | آپلود واقعی از داخل یک صفحه‌ی jsdom با XHR به سرور HTTP واقعی + صف آفلاین |
| `node devserver.test.mjs` | آزمون دودی سرور توسعه‌ی `tools/dev-server.mjs` |
| `node handlers.test.mjs` | بررسی این‌که همه‌ی توابع `onclick`/`onchange` صفحه روی `window` موجودند |
| `node reftest.mjs` | بررسی چرخه‌ی عمر نمونه‌ی PHP در wasm (ابزار تشخیصی) |

آزمون PHP روی سرور خودتان (بدون Node):

```bash
php tools/media-selftest.php
```

همه‌ی دستورها در صورت خطا با کد غیرصفر خارج می‌شوند و برای CI مناسب‌اند.
